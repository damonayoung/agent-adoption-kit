# agent-adoption-kit

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.21943954.svg)](https://doi.org/10.5281/zenodo.21943954)

Adoption telemetry for enterprise AI agents — a method for locating where a population stalls, designed to run entirely inside your own environment.

Companion code for the paper *Adoption Telemetry: Measuring Enterprise AI Adoption from Production Signals* — DOI: 10.5281/zenodo.21943954 (https://doi.org/10.5281/zenodo.21943954), arXiv:2608.23617 (https://arxiv.org/abs/2608.23617).

## What this is

A reference implementation of **NANTE**: it computes change-management stage progression — Notice, Attempt, Navigate, Transform, Embed — from the production telemetry a deployed agent already emits, deterministically and at cohort level. Given an event stream plus a provisioned-user roster, it classifies where a population sits in the adoption process, locates the stall point, and flags characteristic failure signatures.

## Status

Reference implementation accompanying the paper. All thresholds are proposed defaults, not calibrated against real outcomes (see the paper's Limitations and Research Agenda). Treat every number the kit reports as a structured hypothesis about a cohort, not a validated finding.

The ingestion adapters in `aak/ingest/` are unimplemented stubs. Every result the kit produces today derives from the synthetic populations generated by the simulator. Running NANTE against a live environment requires writing your own extractors, resolving user identity across systems, and mapping events into the canonical schema — none of which ship here. When a source emits no `task_outcome` events, the stages that require outcome evidence (Transform and beyond) report as uncomputable rather than failing: users without outcome data are held at Navigate and excluded from the success-rate failing fraction, the snapshot reports how much of the evaluated pool has outcome coverage, and the `low_task_success` diagnosis is withheld below a proposed coverage floor.

## Install

Requires Python ≥ 3.11.

```bash
pip install -e .
```

To also pull in the test dependency (`pytest`):

```bash
pip install -e ".[dev]"
```

This installs the `aak` command.

## Reproduce the paper's results

Everything below is deterministic at a fixed seed (42) and needs no API key or network. From the repo root:

```bash
make results   # the six per-pathology diagnoses behind Table 1 (stage distribution, score, stall, flags)
make figures   # Figure 2 — paper-theme comparison, exported to out/comparison.pdf
```

These two targets wrap the `aak` CLI — nothing more. Equivalently, by hand:

```bash
# make results wraps: simulate the six seed-42 populations (one healthy + five failure modes),
# then classify each population's cohort-1.
mkdir -p out
for p in healthy shallow_plateau awareness_gap ability_gap reinforcement_decay champion_dependency; do
  aak simulate --pathology "$p" --seed 42 --out "out/$p.db"
  echo "== $p =="; aak analyze "out/$p.db" --cohort cohort-1
done

# make figures wraps: paper-theme comparison of the healthy vs shallow-plateau run, exported to PDF.
aak report --compare out/healthy.db out/shallow_plateau.db \
  --ref-cohort cohort-1 --observed-cohort cohort-1 \
  --theme paper --out out/comparison.html --export-figure out/comparison.pdf
```

In the paper repo, its own `make results` and `make figures` targets drive these same commands (same seed 42, same `cohort-1`, same `--theme paper`) and additionally format the output into the booktabs `tables/pathologies.tex` (Table 1) and pin `figures/comparison.pdf` (Figure 2).

## What NANTE measures

Five stages — **Notice, Attempt, Navigate, Transform, Embed** — each a computable predicate over the event stream. The suite distinguishes six cohort profiles: one healthy trajectory and five failure modes (shallow plateau, awareness gap, ability gap, reinforcement decay, champion dependency). Classification is deterministic and operates at cohort level — never per individual.

## Configuration

All thresholds live in `aak/analytics/thresholds.yaml`. Every value there is marked **PROPOSED** — an illustrative starting point for producing a distinguishable signal, not a calibrated finding.
