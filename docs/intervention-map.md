# NANTE intervention map

Every threshold that feeds these triggers (see `aak/analytics/thresholds.yaml`) is PROPOSED — an unvalidated starting point, not a calibrated finding.

| Trigger | Diagnosis | Prescription | Not this |
|---|---|---|---|
| **Never left Notice** | Access, permission, and awareness gap. | Fix provisioning and policy: verify licenses actually work, remove access friction, and run a targeted awareness push for the specific cohort. | training |
| **Stalled at Attempt** | First-touch value is unproven for this role. | Give role-specific proof of what the tool is for: curated use cases that match this cohort's actual work. | feature tours |
| **Stalled at Navigate** | The tool doesn't fit the real workflow yet. | Redesign the workflow so the tool sits inside the actual task sequence, instead of alongside it. | more licenses |
| **Usage regression** | A cohort that was genuinely, frequently engaged has seen usage collapse from an earlier peak — active users are disengaging. | Visible, renewed leadership sponsorship — the retention mechanism for reversing a real decline in a cohort that was actively using the tool. | assuming they never adopted |
| **Champion dependency** | Adoption is concentrated in a small number of power users; the cohort's invocation volume would collapse if they left. | Distribute ownership: pair champions with peers, document their workflows, and spread responsibility so adoption doesn't ride on a handful of people. | celebrating your power users |
| **Shallow plateau** | Breadth is high and retention looks healthy, but depth of use stays flat — the shallow-plateau pattern the brief's ~2% figure describes. | A workflow-embedding intervention: redesign around deeper task integration, not just more usage of the same shallow interaction. | more usage of the same shallow interaction |
| **Skill gap at Navigate** | Users are attempting real, multi-step work but failing at it — the stall is ability, not workflow fit. | Skill-building and enablement: targeted training, worked examples, and coaching on the specific tasks where success rate is low. | not workflow redesign |
